---
title: Adapters
description: Connect wallet tools to AI frameworks.
---

Adapters map wallet tools to different AI agent frameworks.

## MCP

Run wallet as an MCP server:

```bash
cd apps/examples/saw-mcp
bun install
```

```bash
# Run
bun src/index.ts
```

Configure in Claude Desktop:

```json
{
  "mcpServers": {
    "solana-wallet": {
      "command": "bun",
      "args": ["/path/to/saw-mcp/src/index.ts"],
      "env": {
        "SOLANA_PRIVATE_KEY": "your_key",
        "SOLANA_RPC_URL": "https://api.devnet.solana.com"
      }
    }
  }
}
```

## TanStack AI

```ts
import { toTanstackTools } from '@agentic-wallet/adapters-tanstack';

const tools = toTanstackTools(wallet);
// pass to chat() or generateText()
```

## Vercel AI SDK

```ts
import { toVercelTools } from '@agentic-wallet/adapters-vercel';

const tools = toVercelTools(wallet);
// pass to generateText() or streamText()
```
