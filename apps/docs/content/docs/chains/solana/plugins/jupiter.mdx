Swap tokens, lend assets, and access Jupiter's aggregator on Solana.

## Setup

```ts
const wallet = new SolanaAgentWallet({ ... }).use(jupiterPlugin({ 
  apiKey: process.env.JUPITER_API_KEY 
}));
```

## Tools

| Name | Description |
|------|-------------|
| `jupiter_swap` | Swap tokens via Jupiter's aggregator |
| `jupiter_get_token_price` | Get price for tokens |
| `jupiter_search_token` | Search for tokens by ticker or address |
| `jupiter_get_holdings` | Get wallet's token holdings |
| `jupiter_get_shield` | Check token security (rug check) |
| `jupiter_create_limit_order` | Place a limit order |
| `jupiter_cancel_limit_order` | Cancel a limit order |
| `jupiter_get_limit_orders` | Get open limit orders |
| `jupiter_create_recurring_order` | Create a DCA/recurring order |
| `jupiter_cancel_recurring_order` | Cancel a recurring order |
| `jupiter_get_recurring_orders` | Get recurring orders |
| `jupiter_lend_get_tokens` | Get lendable tokens |
| `jupiter_lend_deposit` | Deposit tokens to earn yield |
| `jupiter_lend_withdraw` | Withdraw from lending |
| `jupiter_lend_get_positions` | Get lending positions |
| `jupiter_lend_get_earnings` | Get lending earnings |
| `jupiter_predict_get_events` | Get prediction market events |
| `jupiter_predict_get_market` | Get prediction market details |
| `jupiter_predict_create_order` | Create prediction market order |
| `jupiter_predict_get_positions` | Get prediction positions |
| `jupiter_predict_close_position` | Close prediction position |
| `jupiter_predict_claim_payout` | Claim prediction winnings |
| `jupiter_predict_get_order_status` | Get prediction order status |
