:::warning
**Work in Progress**

The Raydium plugin is currently a work in progress. Many features have incomplete or broken implementations, especially the write operations (non-readonly tools). Use at your own risk. For production use, we recommend the [Jupiter plugin](/docs/chains/solana/plugins/jupiter) which is fully functional.
:::

## Setup

```ts
import { SolanaAgentWallet, createKeypairProvider } from '@agentic-wallet/solana';
import { raydiumPlugin } from '@agentic-wallet/solana/plugin';

const wallet = new SolanaAgentWallet({
  rpcUrl: 'https://api.devnet.solana.com',
  provider: createKeypairProvider(process.env.SOLANA_PRIVATE_KEY!),
}).use(raydiumPlugin());
```

## Plugin Config

```ts
raydiumPlugin({
  cluster?: 'mainnet' | 'devnet',
  disableLoadToken?: boolean,
  apiRequestTimeout?: number,
  apiRequestInterval?: number,
})
```

## Method Naming

All plugin methods are prefixed with `raydium` to avoid collisions with other plugins.

## Actions

### `raydiumSwapExactIn`

```ts
raydiumSwapExactIn(input: RaydiumSwapExactInInput): Promise<RaydiumSwapResult>
```

Input fields:

- `inputMint: string`
- `outputMint: string`
- `amount?: number | string`
- `amountRaw?: string`
- `slippageBps?: number`

Returns:

- `signatures: string[]`
- `explorerUrls: string[]`
- `inputMint: string`
- `outputMint: string`
- `amountInRaw: string`
- `amountOutRaw: string`
- `minAmountOutRaw: string`
- `routeType: 'amm' | 'route'`

### `raydiumCreatePool`

```ts
raydiumCreatePool(input: RaydiumCreatePoolInput): Promise<{ signatures: string[]; explorerUrls: string[]; pool: unknown }>
```

Input fields:

- `mintA: string`
- `mintB: string`
- `amountA?: number | string`
- `amountB?: number | string`
- `amountARaw?: string`
- `amountBRaw?: string`
- `startTime?: number`
- `feeConfigId?: string`

### `raydiumCreateFarm`

```ts
raydiumCreateFarm(input: RaydiumCreateFarmInput): Promise<{ signatures: string[]; explorerUrls: string[]; farm: unknown }>
```

Input fields:

- `poolId: string`
- `programId?: string`
- `rewards: { mint: string; perSecond: string; openTime: number; endTime: number; rewardType?: 'Standard SPL' | 'Option tokens' }[]`

### `raydiumBurnToken`

```ts
raydiumBurnToken(input: RaydiumBurnTokenInput): Promise<{ signature: string; explorerUrl: string; mint: string; rawAmount: string }>
```

Input fields:

- `mint: string`
- `amount?: number | string`
- `amountRaw?: string`
- `owner?: string` (must currently match connected wallet)


- `mint: string`
