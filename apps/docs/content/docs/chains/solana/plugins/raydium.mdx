## Setup

```ts
const wallet = new SolanaAgentWallet({ ... }).use(raydiumPlugin());
```

## Tools

| Name | Description |
|------|-------------|
| `raydium_swap_exact_in` | Swap tokens on Raydium AMM |
| `raydium_liquidity_create_pool` | Create a liquidity pool |
| `raydium_liquidity_create_farm` | Create a farm |
| `raydium_liquidity_add` | Add liquidity to a pool |
| `raydium_liquidity_remove` | Remove liquidity from a pool |
| `raydium_liquidity_stake` | Stake LP tokens |
| `raydium_liquidity_unstake` | Unstake LP tokens |
| `raydium_liquidity_burn_token` | Burn liquidity tokens |
| `raydium_staking_harvest_rewards` | Harvest farming rewards |
| `raydium_portfolio_summary` | Get portfolio summary |
| `raydium_swap_get_pools_by_mints` | Get pools by token pair |
| `raydium_swap_get_pools_by_ids` | Get pools by IDs |
| `raydium_liquidity_get_pools` | List liquidity pools |
| `raydium_liquidity_get_pool_keys` | Get pool keys |
| `raydium_portfolio_get_token_list` | Get token list |
| `raydium_portfolio_get_token_info` | Get token info |
| `raydium_portfolio_get_wallet_token_balances` | Get wallet token balances |
| `raydium_staking_get_farms_by_ids` | Get farms by IDs |
| `raydium_staking_get_farm_keys_by_ids` | Get farm keys by IDs |
