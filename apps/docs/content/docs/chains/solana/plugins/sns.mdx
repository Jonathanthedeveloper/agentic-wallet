---
title: SNS Plugin
description: Solana Name Service methods and tool contracts for SolanaAgentWallet.
---

The SNS (Solana Name Service) plugin provides comprehensive access to domain registration, resolution, and marketplace operations. This enables agents to register .sol domains, resolve domains to wallet addresses, and participate in the domain marketplace.

## Setup

```ts
import { SolanaAgentWallet, createKeypairProvider } from '@agentic-wallet/solana';
import { snsPlugin } from '@agentic-wallet/solana/plugin';

const wallet = new SolanaAgentWallet({
  rpcUrl: 'https://api.devnet.solana.com',
  provider: createKeypairProvider(process.env.SOLANA_PRIVATE_KEY!),
}).use(snsPlugin());
```

## Plugin Config

```ts
snsPlugin()
// No configuration required - uses default SNS program IDs
```

## Method Naming

All plugin methods are prefixed with `sns` to avoid collisions with other plugins.

## Domain Registration

### `snsRegisterDomain`

```ts
snsRegisterDomain(input: SnsRegisterDomainInput): Promise<SnsTxResult>
```

Input fields:

- `domain: string` - Domain name to register (e.g., "myname.sol")
- `space?: number` - Optional storage allocation (0-10, default 0)

Returns:

- `signature: string`
- `explorerUrl: string`

## Domain Resolution

### `snsResolveDomain`

```ts
snsResolveDomain(input: SnsResolveDomainInput): Promise<SnsResolveResult>
```

Input fields:

- `domain: string` - Domain name to resolve (e.g., "bonfida.sol")

Returns:

- `domain: string`
- `resolvedAddress: string` - The wallet address owning the domain

### `snsGetPrimaryDomain`

```ts
snsGetPrimaryDomain(input: SnsGetPrimaryDomainInput): Promise<SnsPrimaryDomainResult>
```

Input fields:

- `address?: string` - Wallet address to query (defaults to connected wallet)

Returns:

- `domain?: string` - The primary domain
- `reverse?: boolean` - Whether it's a reverse record

### `snsGetAllRegisteredDomains`

```ts
snsGetAllRegisteredDomains(): Promise<unknown>
```

Returns all registered domains globally.

### `snsGetAllRegisteredDomainsForAddress`

```ts
snsGetAllRegisteredDomainsForAddress(input: SnsGetDomainsForAddressInput): Promise<SnsDomainsForAddressResult>
```

Input fields:

- `address?: string` - Wallet address to query (defaults to connected wallet)

Returns:

- `address: string`
- `domains: unknown[]` - Array of domains owned by the address

## Fixed Price Offers (Listings)

Fixed Price Offers allow sellers to list domain names for sale at a predetermined price. Buyers can purchase by paying the specified amount.

### `snsMakeFixedPriceOffer`

```ts
snsMakeFixedPriceOffer(input: SnsMakeFixedPriceOfferInput): Promise<SnsTxResult>
```

Input fields:

- `amount: number` - Price in atomic units (e.g., 1000000 = 1 USDC)
- `mint: string` - Token mint address for payment (e.g., USDC)
- `domain: string` - Domain name being listed
- `seller?: string` - Seller address (defaults to connected wallet)
- `nameOffersId?: string` - Optional custom program ID

### `snsAcceptFixedPriceOffer`

```ts
snsAcceptFixedPriceOffer(input: SnsAcceptFixedPriceOfferInput): Promise<SnsTxResult>
```

Input fields:

- `fixedPriceKey: string` - The offer account public key
- `domain: string` - Domain being purchased
- `buyer?: string` - Buyer address (defaults to connected wallet)
- `source?: string` - Token account for payment (defaults to buyer's ATA)
- `referrer?: string` - Optional referrer address
- `nameOffersId?: string` - Optional custom program ID

## Unsolicited Offers

Unsolicited offers allow buyers to propose a purchase price for a domain not listed for sale. The domain owner can accept or ignore.

### `snsMakeUnsolicitedOffer`

```ts
snsMakeUnsolicitedOffer(input: SnsMakeUnsolicitedOfferInput): Promise<SnsTxResult>
```

Input fields:

- `amount: number` - Offer amount in atomic units
- `domain: string` - Domain name to make offer on
- `mint: string` - Token mint for payment
- `tokenSource: string` - Token account holding the funds (ATA)
- `owner?: string` - Offer owner (defaults to connected wallet)
- `nameOffersId?: string` - Optional custom program ID

### `snsAcceptUnsolicitedOffer`

```ts
snsAcceptUnsolicitedOffer(input: SnsAcceptUnsolicitedOfferInput): Promise<SnsTxResult>
```

Input fields:

- `offerKey: string` - The offer account public key
- `offerOwner: string` - The buyer who made the offer
- `domain: string` - Domain being sold
- `destination: string` - Token account to receive payment
- `offerEscrow: string` - Escrow account from the offer
- `referrer?: string` - Optional referrer address
- `nameOffersId?: string` - Optional custom program ID

### `snsCancelUnsolicitedOffer`

```ts
snsCancelUnsolicitedOffer(input: SnsCancelUnsolicitedOfferInput): Promise<SnsTxResult>
```

Input fields:

- `offerKey: string` - The offer account public key
- `tokenDestination: string` - Token account to return funds to
- `owner?: string` - Offer owner (defaults to connected wallet)
- `nameOffersId?: string` - Optional custom program ID

## Category Offers

Category Offers allow buyers to bid on entire domain categories (e.g., all 4-character .sol domains). Sellers can accept offers for domains in that category.

### `snsMakeCategoryOffer`

```ts
snsMakeCategoryOffer(input: SnsMakeCategoryOfferInput): Promise<SnsTxResult>
```

Input fields:

- `amount: number` - Total offer amount in lamports
- `nbDomains: number` - Number of domains wanted
- `categoryKey: string` - Category public key (e.g., from @bonfida/sns-categories)
- `buyer?: string` - Buyer address (defaults to connected wallet)
- `nameOffersId?: string` - Optional custom program ID

### `snsAcceptCategoryOffer`

```ts
snsAcceptCategoryOffer(input: SnsAcceptCategoryOfferInput): Promise<SnsTxResult>
```

Input fields:

- `categoryOfferKey: string` - The category offer account public key
- `domain: string` - Domain being sold
- `memberKey: string` - Category membership key for the domain
- `seller?: string` - Seller address (defaults to connected wallet)
- `referrer?: string` - Optional referrer address
- `nameOffersId?: string` - Optional custom program ID

## P2P Offers

P2P (Peer-to-Peer) Offers enable direct transactions between a buyer and seller without public listing.

### `snsMakeP2POffer`

```ts
snsMakeP2POffer(input: SnsMakeP2POfferInput): Promise<SnsTxResult>
```

Input fields:

- `amount: number` - SOL amount in lamports (can be 0)
- `baseDomains: string[]` - Domains the creator wants to sell
- `quoteDomains: string[]` - Domains the creator wants to buy (from counterparty)
- `counterParty: string` - The other party's wallet address
- `endDate?: number` - Unix timestamp when offer expires
- `owner?: string` - Offer creator (defaults to connected wallet)
- `nameOffersId?: string` - Optional custom program ID

### `snsAcceptP2POffer`

```ts
snsAcceptP2POffer(input: SnsAcceptP2POfferInput): Promise<SnsTxResult>
```

Input fields:

- `p2pKey: string` - The P2P offer account public key
- `nameOffersId?: string` - Optional custom program ID

### `snsCancelP2POffer`

```ts
snsCancelP2POffer(input: SnsCancelP2POfferInput): Promise<SnsTxResult>
```

Input fields:

- `p2pKey: string` - The P2P offer account public key
- `owner?: string` - Offer creator (defaults to connected wallet)
- `nameOffersId?: string` - Optional custom program ID
