## `createSolanaKeypairFromSecretKey(input)`

Input type: `SolanaSecretKeyInput`

```ts
type SolanaSecretKeyInput = Uint8Array | number[] | string;
```

Accepted `string` formats:

- base58
- base64
- hex (`0x...` or plain)
- JSON byte array (`[1,2,...]`)
- comma-separated bytes (`1,2,...`)

Rules:

- 32 bytes -> `Keypair.fromSeed`
- 64 bytes -> `Keypair.fromSecretKey`
- other lengths throw `INVALID_ACTION`

## `createSolanaKeypairFromEnv(envVar?)`

Reads secret key from env var (default: `SOLANA_PRIVATE_KEY`) and returns `Keypair`.

## `createKeypairProvider(privateKey)`

Builds a `SolanaWalletProvider` from a secret key input.

Returned provider supports:

- `publicKey`
- `signTransaction`
- `signAllTransactions`
- `sendTransaction`
- `signAndSendTransaction`
