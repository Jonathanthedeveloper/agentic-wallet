Tools available without any plugins.

## Tools

| Name | Description |
|------|-------------|
| `solana_get_balance` | Fetches a user's SOL or SPL token balance |
| `solana_transfer` | Transfer SOL or SPL tokens to another address |
| `solana_request_airdrop` | Request SOL airdrop on devnet/testnet |
