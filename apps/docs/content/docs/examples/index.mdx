This section contains working examples demonstrating how to use Agentic Wallet with various agent frameworks and interfaces.

## Available Examples

| Example | Description | Use Case |
|---------|-------------|----------|
| **[Chat Interface](/docs/examples/chat)** | Talk to your wallet naturally | **Most user-friendly** - just chat |
| [CLI](/docs/examples/cli) | Command-line interface for agents | OpenClaw, ClawDBot, autonomous agents |

| [Trading Agent](/docs/examples/trading-agent) | Autonomous DeFi trading agent | Automated portfolio management |

## Chat Interface (Recommended)

The Chat Interface is the easiest way to experience Agentic Wallet — **just talk to it**:

- **Natural language** - "Swap my SOL for USDC" just works
- **Real-time feedback** - Watch the AI execute tools live
- **Markdown support** - Transaction links, formatted responses
- **Browser-based** - Private keys stay in your browser

```bash
cd apps/examples/saw-chat
bun run dev
```

[View Chat Guide →](/docs/examples/chat)

## CLI Example

The CLI is designed for **autonomous AI agents** that need to programmatically manage wallets:

- Execute shell commands for wallet operations
- Run as MCP server for MCP-compatible agents
- Integrate with agents like OpenClaw, ClawDBot

```bash
# Quick start
agent-wallet address
agent-wallet balance
agent-wallet tool run jupiter_swap '{"inputMint":"...","outputMint":"...","amount":"0.1"}'
```

[View CLI Guide →](/docs/examples/cli)

## MCP Server Example

The MCP server is for **AI agents that support the Model Context Protocol**:

- Claude Desktop
- Cursor
- Continue (VS Code)
- Roo
- Codeium

Configure your agent to connect to the MCP server and get instant Solana wallet capabilities.

[View MCP Guide →](/docs/examples/mcp)

## Trading Agent Example

The Trading Agent is an **autonomous DeFi trading agent** that:
- Runs continuously, making AI-driven trading decisions every 60 seconds
- Uses Vercel AI SDK + OpenRouter (Gemini 2.5 Pro)
- Executes swaps, limit orders, lending via Jupiter
- Enforces risk rules (max 30% concentration, keeps 0.02 SOL for fees)

[View Trading Agent Guide →](/docs/examples/trading-agent)

## Chat Interface Example

The Chat Interface is a **web-based chat UI** that:
- Provides a conversational interface for wallet interaction
- Shows tool execution in real-time with collapsible details
- Supports markdown rendering with syntax highlighting
- Built with TanStack Start + Vercel AI SDK

[View Chat Interface Guide →](/docs/examples/chat)

## Running Examples

All examples require:
1. A Solana private key in the environment
2. An RPC endpoint (devnet by default)
