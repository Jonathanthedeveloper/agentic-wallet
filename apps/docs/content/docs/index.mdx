## What This Library Isn't

Agentic Wallet is **not**:
- A wallet UI or browser extension
- A replacement for Phantom, Solflare, or other consumer wallets
- A custody solution — it's self-custody
- Limited to just swapping tokens

## What It Is

Agentic Wallet turns your Solana wallet into a set of **tools** that AI agents can call directly. It handles:

- Transaction signing and execution
- DeFi integrations (Jupiter, Pump.fun, Raydium, SNS)
- Works with any AI framework (TanStack AI, Vercel AI SDK, MCP)

## Quick Example

```ts
import { chat } from '@tanstack/ai';
import { openRouterText } from '@tanstack/ai-openrouter';
import { toTanstackTools } from '@agentic-wallet/adapters-tanstack';
import { SolanaAgentWallet, createKeypairProvider } from '@agentic-wallet/solana';
import { pumpfunPlugin, jupiterPlugin } from '@agentic-wallet/solana/plugin';

// Create wallet with plugins
const wallet = new SolanaAgentWallet({
  provider: createKeypairProvider(process.env.PRIVATE_KEY!),
  rpcUrl: 'https://api.mainnet-beta.solana.com',
}).use(pumpfunPlugin()).use(jupiterPlugin());

// Convert wallet tools for TanStack AI
const tools = toTanstackTools(wallet);

// AI agent can now call tools naturally
const response = await chat({
  message: 'Swap 0.1 SOL for USDC',
  adapter: openRouterText('google/gemini-2.5-pro'),
  tools,
});
```

## Packages

| Package | Description |
|---------|-------------|
| `@agentic-wallet/core` | Base wallet class and plugin types |
| `@agentic-wallet/solana` | Solana implementation with plugins |
| `@agentic-wallet/adapters-mcp` | MCP protocol adapter |
| `@agentic-wallet/adapters-tanstack` | TanStack AI adapter |
| `@agentic-wallet/adapters-vercel` | Vercel AI SDK adapter |

## What You Can Build

- **Trading agents** that autonomously swap, DCA, and rebalance
- **Yield optimizers** that deposit, stake, and harvest
- **Portfolio managers** that monitor and adjust positions
- **Any agent** that needs to move money on Solana
