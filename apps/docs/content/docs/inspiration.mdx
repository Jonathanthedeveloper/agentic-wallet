## Wallet Infrastructure

- **[Solana Wallet Adapter](https://github.com/anza-xyz/wallet-adapter)** - The standard React context providers for wallet connections. We used their pattern of separating connection state from signing logic.

- **[Reown AppKit](https://reown.com/)** - Formerly WalletConnect. Clean wallet modal and provider interface.

- **[Privy](https://privy.io/)** - Embedded wallets done right. Their React hooks API for signing transactions influenced our provider interface.

## AI Agents

- **[TanStack AI](https://tanstack.com/ai)** - The server tools pattern. `toTanstackTools()` directly maps our wallet tools to their `ServerTool` format.

- **[Vercel AI SDK](https://sdk.vercel.ai/)** - Streaming-first approach. Their tool execution model inspired our adapter design.

- **[OpenAI Agents SDK](https://openai.com/index/introducing-agents-sdk/)** - Showed how to structure tool definitions for LLM execution.

## DeFi Protocols

- **[Jupiter](https://jup.ag/)** - The aggregator that makes Solana trading possible. Their API design for swaps, limit orders, and lending is excellent.

- **[Pump.fun](https://pump.fun/)** - Demonstrated that token creation should be accessible. Their bonding curve mechanics are well-documented.

- **[Raydium](https://raydium.io/)** - AMM and liquidity pools on Solana.

## Learning Resources

- **[Solana Cookbook](https://solanacookbook.com/)** - Practical Solana development patterns.

- **[Solana Program Library](https://github.com/solana-labs/solana-program-library)** - Reference implementations for SPL tokens.

- **[Anchor](https://www.anchor-lang.com/)** - The standard for Solana smart contracts. Their IDL-based approach informed how we think about protocol interfaces.
